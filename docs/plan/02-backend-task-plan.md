# 后端任务计划（Deepseek-V4-Pro）

> 本文件由后端 Agent 维护。所有端点字段以 `openapi.yaml` 为准。

## 阶段 0：契约冻结与脚手架

- [ ] 确认 `openapi.yaml` v1 已双审冻结。
- [ ] 建立 `apps/api` NestJS 项目结构与模块边界。
- [ ] 配置 Prisma / TypeORM + PostgreSQL 迁移链路。
- [ ] 接入共享契约包 `@nodusfall/contract`。
- [ ] 搭建本地 mock 环境与 OpenAPI 文档页。

## 阶段 1：认证与用户

- [ ] 注册、登录、刷新、登出（JWT access + refresh，refresh 存 Redis）。
- [ ] `GET /v1/users/me`、`PATCH /v1/users/me`。
- [ ] 角色模型：`guest` / `member` / `editor` / `moderator` / `admin`。
- [ ] 密码哈希（argon2 或 bcrypt）、输入校验、登录限流。

验收：错误码与 OpenAPI 一致；刷新令牌可轮换且可撤销。

## 阶段 2：Wiki 内容

- [ ] 分类与标签资源。
- [ ] Wiki 页面 CRUD、slug 唯一、发布状态。
- [ ] 版本历史：每次编辑生成 revision，支持查看差异。
- [ ] Markdown 内容存储与清理（防 XSS）。
- [ ] 列表过滤：分类、标签、状态、关键词、排序、分页。

验收：`GET /v1/wiki/pages/{slug}` 返回含版本信息的完整页面；历史版本只读。

## 阶段 3：攻略

- [ ] 攻略 CRUD 与发布状态。
- [ ] 攻略标签、关联角色/武器/副本等元数据。
- [ ] 评分：平均分、评分人数、防重复评分。

验收：评分幂等；攻略与 Wiki 数据模型边界清晰。

## 阶段 4：论坛

- [ ] 板块与板块内主题列表。
- [ ] 主题 CRUD、置顶 / 锁定。
- [ ] 回帖 CRUD、楼层、软删除。
- [ ] 点赞 / 取消点赞、收藏 / 取消收藏。

验收：列表使用统一分页；点赞、收藏幂等。

## 阶段 5：评论与审核

- [ ] Wiki / 攻略评论。
- [ ] 举报创建与处理（P2 可先做数据结构）。
- [ ] 审核状态机：`pending` / `approved` / `rejected`。

验收：违规内容可隐藏并保留审计日志。

## 阶段 6：搜索与上传

- [ ] 跨内容搜索接口。
- [ ] 图片上传与 S3 兼容存储。
- [ ] 图片大小、类型、病毒扫描或基本校验（P2 可简化为类型/大小限制）。

## 阶段 7：横切能力

- [ ] 统一错误响应（RFC 7807）与请求 ID。
- [ ] 限流中间件与 `429` 响应头。
- [ ] 结构化日志、指标、健康检查。
- [ ] CORS、安全头、输入清洗。
- [ ] 备份与迁移回滚策略。

## 阶段 8：测试与交付

- [ ] 单元测试覆盖核心 service。
- [ ] 集成测试覆盖主要资源。
- [ ] 契约测试：用 OpenAPI 校验响应结构。
- [ ] 提供 Docker Compose 本地环境。

## 依赖前端的事项

- 图片尺寸约定、允许的 Markdown 扩展（如表格、图片、目录）。
- 编辑器保存草稿的时机与字段（是否前端本地草稿）。
