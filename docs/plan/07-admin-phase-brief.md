# 07 - 阶段计划：后台管理能力（发给后端负责人的指令存档）

> 状态：已发送（2026-09-01）。本文档是发给后端 Agent（DeepSeek）的阶段指令存档，供双方对照。
> 流程约定不变：后端先走 `contract/*` PR 改 openapi.yaml，前端确认冻结后再实现，全部走 PR 到 develop。

## 背景（前端现状）

前端已有 `/admin/wiki`、`/admin/guides` 管理列表（含精华标记开关），首页有轮替推荐框（5 个轮替位）、「最新动态 / 精华推荐」双栏（各 6 个位置）、总览页六个图文/视频分栏、页底官方渠道区。这些目前都缺后端管理接口，内容无法持久化配置。

## 本期契约需求（按优先级）

### 1. 板块与分类管理

- 论坛板块 CRUD：`POST/PATCH/DELETE /admin/forum/boards`（slug、名称、描述、sortOrder）
- Wiki 分类 CRUD：`POST/PATCH/DELETE /admin/wiki/categories`
- 攻略分类（如有独立分类体系，同上）
- 删除约束：板块/分类下有内容时禁止删除或要求迁移，契约里写清行为

### 2. 内容管理

- 精华/置顶：Wiki 条目、攻略、论坛主题的 `featured` / `pinned` 标记 PATCH（前端已有开关，确认字段名与现有契约一致）
- 内容状态管理：draft/published/archived 的 PATCH（管理员越权改任意内容）

### 3. 页面 CMS 扩展（在现有 home/world CMS 基础上）

- 首页轮替框：5 个槽位，每槽 {imageUrl 或 videoUrl, title, linkKind, linkTarget}，支持图片**和视频**两种媒体
- 首页「最新动态 / 精华推荐」双栏：各 6 槽，可手动指定内容或选「自动取最新/精华」
- 总览页六个分栏：每栏 {标题, 正文, 媒体（图/视频）, 排序}，管理员可增删改
- 官方渠道区：可配置列表 {名称, url, 图标key}，至少支持官网/B站/抖音；另加一个「官方信息转载」独立栏框（标题+链接+发布时间列表）

### 4. 权限

- 以上全部仅 ADMIN；契约注明 403 行为

## 约束

- 不动已有的用户中心、认证、评论契约（PR #45 已冻结，除非有兼容性问题单独提）
- 列表接口继续带 `bookmarkedByMe` / `likedByMe` 可选登录态回填的惯例
- RFC 7807 错误、写操作 Idempotency-Key、429 Retry-After 保持现有惯例
- 契约 PR 描述里逐条列新增端点，前端逐条确认

## 备注

- 第 2 条「精华标记」前端已有一版实现，后端确认现有契约字段够用即可，不一定是新工作。
- 契约冻结后前端重跑 codegen，实现 /admin 各管理页。
