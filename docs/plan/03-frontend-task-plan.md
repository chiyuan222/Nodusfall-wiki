# 前端任务计划（Kimi k3）

> 本文件由后端 Agent 起草，最终以 **Kimi k3 审查并修改后的版本为准**。
> Kimi 可在本节自由增删任务，但不得改变契约字段；如需字段调整，请发起契约变更 PR。

## 阶段 0：美术导向与设计系统

- [ ] 确定整体视觉关键词与 Nodusfall 世界观气质（建议：冷峻、星轨、结绳 / 源点母题）。
- [ ] 建立色彩 token、字体层级、间距、圆角、阴影、动效时长。
- [ ] 确立深色主题为默认，补充浅色主题（或至少可扩展）。
- [ ] 组件库：按钮、输入、卡片、标签、面包屑、分页、编辑器、评论、Toast。
- [ ] 移动端优先的响应式断点。

## 阶段 1：站点壳与路由

- [ ] Next.js App Router 项目结构与路由地图。
- [ ] 全局布局、导航、页脚、非官方免责声明。
- [ ] SEO：metadata、OpenGraph、sitemap、robots。
- [ ] 错误页、404、加载骨架屏。

## 阶段 2：首页与 Wiki

- [ ] 首页：推荐条目、热门攻略、最新论坛动态。
- [ ] Wiki 列表：分类导航、标签筛选、搜索入口、分页。
- [ ] Wiki 详情：Markdown 渲染、目录、版本历史、评论区。

## 阶段 3：攻略

- [ ] 攻略列表：筛选、排序、评分展示。
- [ ] 攻略详情：配队 / 养成信息展示、评分组件、相关攻略。

## 阶段 4：论坛

- [ ] 板块列表与主题列表。
- [ ] 主题详情、楼层回复、点赞、收藏。
- [ ] 发帖 / 回复编辑器与登录态提示。

## 阶段 5：用户中心与编辑器

- [ ] 登录 / 注册 / 资料页。
- [ ] Markdown 编辑器（预览、图片上传、草稿）。
- [ ] 我的攻略 / 我的帖子 / 收藏 / 通知（P2）。

## 阶段 6：体验与验收

- [ ] 无障碍（键盘、对比度、语义标签）。
- [ ] 性能：图片懒加载、字体优化、首屏预算。
- [ ] 视觉回归与 Storybook 文档。
- [ ] 与后端 mock / 真实接口联调，确认字段无偏差。

## 前端对后端契约的诉求（可提出）

- 列表接口是否需要在响应中直接给“是否已点赞 / 已收藏”等当前用户状态，避免额外请求。
- 搜索接口的结果合并规则。
- 图片上传后返回的 URL 是否支持 CDN / 缩放参数。
