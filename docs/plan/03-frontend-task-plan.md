# 前端任务计划（Kimi k3）

> 本版本由 Kimi k3 审查并修订（详见 [前端审查与美术导向提案](../design/frontend-review.md) §5）。
> Kimi 可在本节自由增删任务，但不得改变契约字段；如需字段调整，请发起契约变更 PR。

## 阶段 0：美术导向与设计系统

- [ ] 确定整体视觉关键词与 Nodusfall 世界观气质：**已选定「结绳源点（Nodus Origin）」**，深色冷底 + 琥珀点缀 + 衬线标题，节点-连线为统一图形母题。
- [ ] 建立色彩 token、字体层级、间距、圆角、阴影、动效时长（草案见提案 §3）。
- [ ] **（增）** token 双写机制：CSS Custom Properties 为唯一真相，Tailwind theme 由其生成，避免两份真相漂移。
- [ ] 确立深色主题为默认；浅色主题仅预留 token 结构，实现列入 P2。
- [ ] **（增）** 母题图形资产：节点-连线 SVG 组件、favicon、空状态插画、加载动画，全部参数化生成，不依赖外部图库。
- [ ] 组件库：按钮、输入、卡片、标签、面包屑、分页、编辑器、评论、Toast。
- [ ] 移动端优先的响应式断点（sm/md/lg/xl，见提案 §3.5）。

## 阶段 0.5：API 客户端与类型（新增，所有页面阶段的前置）

- [ ] `pnpm codegen` 从 openapi.yaml 生成 TS 类型，前端只消费生成类型，不手写字段。
- [ ] 封装 fetch 客户端：RFC 7807 错误统一处理（按 `code` 分支、限流读 `Retry-After`、校验错误 `errors[]` 映射表单字段）。
- [ ] 认证会话管理：accessToken 过期（示例 900s）前用 refreshToken 无感刷新；401 拦截后刷新重试一次；登出调 `DELETE /auth/sessions/{id}`。
- [ ] Prism mock 联调脚本，页面开发不等待后端实现。
- [ ] 写操作统一带 `Idempotency-Key`（可选但默认开启）。

## 阶段 1：站点壳与路由

- [ ] Next.js App Router 项目结构与路由地图（见提案 §1.2）。
- [ ] 全局布局、导航（桌面 SiteHeader / 移动 BottomTabBar 双形态）、页脚、非官方免责声明。

- [ ] 错误页、404、加载骨架屏（骨架与真实布局 1:1，避免 CLS）。

## 阶段 2：首页与 Wiki

- [ ] 首页：推荐条目、热门攻略、论坛板块速览。**（改）** 数据为 3 个并发请求；"跨板块最新动态"受契约限制暂不实现，待契约补 `GET /forum/threads` 全局列表或确认搜索替代（提案 §6.4）。
- [ ] Wiki 列表：分类导航、标签筛选、搜索入口、分页。
- [ ] Wiki 详情：Markdown 渲染、粘性目录、版本历史、评论区。
- [ ] 版本历史页：节点-连线时间线（母题落点）。

## 阶段 3：攻略

- [ ] 攻略列表：筛选、排序、评分展示。
- [ ] 攻略详情：配队 / 养成信息展示、相关攻略。
- [ ] **（增）** 评分面板：平均分 + 分布条形图（`RatingSummary.distribution`）+ 我的评分输入与回显（回显依赖契约补 `myScore`，提案 §6.1）。

## 阶段 4：论坛

- [ ] 板块列表与主题列表。
- [ ] 主题详情、楼层回复、点赞、收藏。
- [ ] 发帖 / 回复编辑器与登录态提示（AuthGate 拦截，浏览不强制登录）。

## 阶段 5：用户中心与编辑器

- [ ] 登录 / 注册 / 资料页。
- [ ] Markdown 编辑器：双栏预览（移动端 Tab 切换）、图片拖拽上传（`POST /uploads` / presign，失败重试）。
- [ ] **（改）** 草稿 = localStorage 本地草稿自动保存（契约的 `status=draft` 是发布状态，不是草稿箱）。
- [ ] 我的攻略 / 我的帖子：**Blocked**——契约缺按作者过滤或 `GET /users/me/*` 端点（提案 §6.2）。
- [ ] 我的收藏 / 通知：**Blocked / P2**——收藏列表端点缺失（提案 §6.2）；通知为 P2 范围。

## 阶段 6：体验与验收

- [ ] 无障碍：键盘全可达、对比度 AA、语义标签、`prefers-reduced-motion`。
- [ ] **（增）** 性能预算硬指标：首屏 LCP < 2.5s；首屏 JS ≤ 170KB（gzip）；衬线标题字体子集 < 80KB；图片懒加载 + 预设宽高比，CLS ≈ 0。
- [ ] 视觉回归与 Storybook 文档（组件三态截图作为基线）。
- [ ] 与后端 mock / 真实接口联调，确认字段无偏差。

## 前端对后端契约的诉求（已提出，详见提案 §6）

- 列表 / 详情接口统一返回当前用户状态：`likedByMe` / `bookmarkedByMe` / `myScore`，避免 N+1 请求。
- 用户中心需要"我的攻略 / 帖子 / 收藏"端点，或列表支持 `author` 过滤参数。
- 论坛缺跨板块"最新主题"端点；首页聚合方案待确认。
- 建议详情 schema 返回 `canEdit` / `canDelete`，前端不做权限推断。
- 搜索结果建议返回 `slug` 而非拼接好的 `url`。
